# Procesverbalet e Futsallit - FFK

Aplikacion web (funksionon edhe offline) per procesverbalet e futsallit.
Hapet si aplikacion ne ekran te plote kur shtohet ne ekranin kryesor te telefonit.

Skedari kryesor: `index.html`. Skedaret `manifest.webmanifest`, `sw.js` dhe ikonat
sigurojne instalimin dhe punimin offline - mos i fshini.
